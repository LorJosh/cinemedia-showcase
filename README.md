# CineMedia Showcase

Taller de JavaScript moderno (ES6+): modo claro/oscuro, likes por tarjeta y formulario de valoraciones con SweetAlert2 y Canvas-Confetti.

Autor: Joshua Lores Florez

## Cómo ejecutarlo

Abrir `index.html` con Live Server. Las librerías se cargan desde jsDelivr, así que se necesita conexión a internet.
